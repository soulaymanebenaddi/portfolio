# Portfolio de Soulaymane Benaddi

Portfolio personnel de Soulaymane Benaddi, développeur Full-Stack à Montréal.

## Technologies

- React
- TypeScript
- Sass
- Material UI
- GitHub Actions
- GitHub Pages

## Développement local

```bash
npm install
npm start
```

Le site est ensuite accessible à l'adresse `http://localhost:3000`.

## Vérifications

```bash
npm test -- --watchAll=false
npm run build
```

## Déploiement

Chaque modification poussée sur la branche `main` déclenche automatiquement la compilation et le déploiement sur GitHub Pages.

Site publié : [soulaymanebenaddi.github.io/portfolio](https://soulaymanebenaddi.github.io/portfolio/)
